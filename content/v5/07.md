## 本地 vs API 的总账：电费、利用率与矿卡折价

[显卡市场生存指南](#/v4/10)讲完怎么挑卡，这一章先按住你的手：下单之前，先回答"我为什么要本地"。SPOTLITE 上线了一个叫"紧急刹车"的劝退项目，上线一周 100 个 star（GitHub 上的收藏数），私信被拉爆，问的全是"显卡去哪买、哪家店靠谱、2080Ti 和 3090 和 5090 怎么推荐"——先买卡再想用途，是新手最普遍的路径。本章把本地推理写成一笔 TCO（Total Cost of Ownership，总拥有成本）账：购置成本 + 使用成本（电费）+ 时间精力 + 风险折价。类比买车与打车：私家车再香，一年打不了几次车，固定成本永远摊不平；API（云端推理服务）是打车，用了才付钱。

> **案例（视频出处：BV1KKE96CELt）** "玩本地 AI 是一个巨耗钱的事情，它不可能从成本角度给到你任何帮助……如果你是图它的成本的话，不要去买。"这个判断不来自参数对比，来自下面这道乘法题。

### 满载一天的极限产出：864 万 token

本地方案的产出上限由 decode 吐字速度决定（口径见 [tok/s](#/v3/01)、[Prefill 与 Decode](#/v1/07)），算式只有一行：

`日产出 token = 3600 秒 × 24 小时 × tok/s`

一天共 86400 秒。哪怕单并发跑到 [双 2080Ti 27B 方案](#/v5/01)实测的 100 tok/s（含 MTP 加速），满打满算也只有 864 万 token——这是那台机器 24 小时不眠不休的物理上限，你上班、睡觉的时间全算进去。

> **案例（视频出处：BV1KKE96CELt）** "3600 秒乘以 24，然后每秒再乘以 100……那也就才 800 多万 token，一天满打满算全部拉满。"（机器字幕把"800 多万 token"转写成"800 多 token"，校正后如上。）

### 电费换 API：20 块钱能买什么

功耗与电费的算术在[平台与功耗](#/v4/09)已算过：600W 整机开满 24 小时约 14.4 度电。UP 主给的口径是"十几到 20 块"一天——注意这是**开着机就在烧**的固定成本，没人用也照烧。

> **案例（视频出处：BV1KKE96CELt）** "你的电费可能就要 20 块钱啊，十几到 20 块。"而某国产大模型 flash 档的正式价是"每百万输出两块钱"，"这已经是正式价格了，不是一般的价格"。（口播型号名被机器字幕转写坏了；从语境看就是[模型生态与幻觉](#/v1/10)里那类 200B 档 flash MoE，如 DeepSeek V4 Flash。）

两笔账放进一张表：

| 口径 | 数字 |
| --- | --- |
| 本地满载 24h 产出 | 约 864 万 token |
| 本地 24h 电费 | 十几到 20 元 |
| 20 元能买的 API 输出量 | 1000 万 token |
| API 模型档位 | 总参数远大于 27B 的 flash MoE |
| 本地方案对标 | 27B 稠密模型 |

同样 20 元，API 买回 1000 万输出 token，比本地满载一天的极限还多约 16%，而且模型更强：按 [MoE：总参数与激活参数](#/v1/09)的分法，这个 flash 档"参数量比它要大很多，虽然激活量可能不一定比它要多"，所以"性能它一定比 27B 模型要强大"。于是得到那句总判决——**"我们用了一个更贵的价格，去用一个更弱的模型。"**

### 利用率：满载已经是最偏袒本地的假设

864 万还是按全天满载送的分。真实家用的利用率（utilization）远低于 100%：上班、睡觉、周末出门，机器要么关机（购置成本摊得更薄），要么开着吃灰（电费照烧）。设利用率为 η，日均产出 = 864 万 × η，则本地每百万 token 的电费成本 = 20 ÷（864 万 × η ÷ 100 万）：

| η | 日产出 | 本地每百万 token 电费成本 | API 同口径 |
| --- | --- | --- | --- |
| 100% | 864 万 | 约 2.3 元 | 2 元 |
| 20% | 约 173 万 | 约 11.6 元 | 2 元 |
| 5% | 约 43 万 | 约 46 元 | 2 元 |

满载都只能勉强打平，利用率一掉就是十倍差距——"远低于满载"这五个字，就是本地账本最重的一块砝码。

### 账本里还有三笔没算

| 隐性成本 | 说明 |
| --- | --- |
| 购买成本 | 双 2080Ti 方案 3500~4500 元，按年摊销 |
| 搭建精力 | 装机、驱动、量化选型、排障投入的时间 |
| 质量风险折价 | 2080Ti/3090 是矿潮重灾区，体质损耗加翻车概率，二手残值打折（风险地图见[显卡市场生存指南](#/v4/10)） |

> **案例（视频出处：BV1KKE96CELt）** "前期的硬件搭建精力，还有购买成本，以及这个显卡遇到的这样一个质量风险"——这三项在电费对比里都还没算，账就已经输了，所以"光是这个使用长期使用成本它就不划算"。

### "紧急刹车"到底在刹什么

不是宣判本地 AI 没价值。隐私、离线、亲手折腾出来的理解，这些 API 买不到；但如果动机那一栏写的是"省钱"，本章的算术就是那脚刹车——"所以大家一定要打住"。以终为始：先写清用途，再决定买不买卡（方法整理见[七个方法论模式](#/v6/01)，选卡顺序见[显卡天梯](#/v5/04)）。

## 怎么验证

- **复核那道乘法题**：`python3 -c "print(3600*24*100)"` 输出 8640000；把 100 换成你实测的单并发 TG 再算一遍自己的上限。
- **读 API 价格页**：打开任一国产模型厂商的定价页，找"每百万输出 token"一栏，确认输入与输出分开计价、flash 档确实在 2 元/百万的量级，再用"电费 ÷ 单价"算出能买多少。
- **量你的利用率**：让推理服务跑一周，从日志或 `/metrics`（vLLM 自带）统计实际生成的 token 总数，除以（86400 × 你的 TG × 7）得到 η，代进上表第三列看你的每百万成本。
- **查残值**：在二手平台搜目标卡型的当前成交价，对比一年前的行情估年折旧率，把（购置价 − 残值）摊进每百万 token 成本，看结论是否反转。
