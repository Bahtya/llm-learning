## 两万元的选择题

[统一内存与 offloading](#/v4/08) 给过结论：要跑 200B 级的超大规模[混合专家模型（MoE，Mixture of Experts）](#/v1/09)（总参数巨大、激活参数很小），万元级统一内存（Unified Memory）主机比多卡堆显存更对路，代表平台是 AMD Strix Halo。这一章把结论折成钱：同样的预算，买 AI Max 395 还是新款 495？多花两万到底买了什么？哪些负载配走这条路？

先给个类比。显存像酒店客房：单价低，但要整层整层包下，楼层之间（多卡互联）还得加钱修走廊；统一内存像包下一整层开放办公区：每平米贵一点，可 CPU 和 GPU 坐在同一张桌上递东西，不用出门跑腿。大 MoE 最缺的不是桌面速度，是"坐得下所有专家"的面积，所以预算优先砸容量。

## 395 vs 495：多花的两万只买了 64G

| | AI Max 395 | AI Max 495 |
| --- | --- | --- |
| 集成显卡核心 | 8060S（编号 GFX1151） | 8065S（小幅超频） |
| 算力档位 | 约 RTX 3060M~3070M（M=笔记本版） | 几乎不变 |
| 统一内存 | 128G（64G 版等于买错） | 192G |
| 可分配显存上限 | 96G | 160G |
| 标价 | 约 2 万 | 约 4 万 |

这笔账的原理是**边际价格**：增量价格除以增量资源。495 相对 395 的唯一实质升级是内存 128G→192G，核心只是超了一点点频，于是：

```formula
Δ价格 ÷ Δ内存 = 2 万元 ÷ 64G ≈ 312 元/GB
```

> **案例（视频出处：BV1otY26LE8w）**
> UP 只给 495 一颗星："你多出来这 2 万，你只买了一个 64G 的 LPDDR5X 内存。"同样的 4 万买两台 395：算力翻倍，两台机器之间有 PCIe 直出和 USB4 80G 双向互联（见 [NVLink 与 PCIe 全家桶](#/v4/07)），这个带宽相对算力绰绰有余。反过来的教训是 395 必须买 128G 版：64G 版能做的事和 128G 完全不一样，"恭喜你买错了"。

平台底子顺带一笔：395 是 x86 架构，装 Windows 打游戏、装 Ubuntu 都不折腾，整机 150~200W；ROCm 支持也在变好（见 [CUDA vs ROCm](#/v3/09)），但它不支持 FP8 低精度浮点（见 [FP8 与 NVFP4](#/v2/02)）。

## 带宽换容量：吐字保住、吞字让步

[带宽决定 Decode、算力决定 Prefill](#/v4/03) 讲过取舍：吐字（decode）每出一个 [token](#/v1/01) 都要把用到的权重读一遍，速度被带宽按住；吞字（prefill）是并行的大矩阵乘，看算力。统一内存的 LPDDR5X 有 200 多 GB/s 的等效显存带宽，已到入门显卡水平，395 标称 256GB/s。所以这笔交易等于：**用低于高端显卡的带宽，换大容量和零拷贝，代价由 prefill 一项承担。**

> **案例（视频出处：BV1otY26LE8w）**
> 两个参照系：Mac M3 Ultra 带宽 800GB/s，碾压 200G 档统一内存；而优化空间几乎全在吞字侧，社区项目 hello-flash（针对 Strix Halo 统一内存的高性能推理项目）把千问 3.8-flash 在 395 上的预填充从原版 llama.cpp 的 200~300 拉到轻松破 1000，解码也只有 40~50 tok/s。带宽锁死吐字上限，吞字还有大把可挖。（注：与 [统一内存与 offloading](#/v4/08) 实测的 900+ 非同一模型/版本，口径不同。）

## CPU 调度：大 MoE 为什么讨厌多卡

MoE 的路由计算仍在 GPU 上跑，但它的编排调度让 CPU 参与明显变多，对每台机器之间的时延和存储空间的统一度要求极高（CPU 还包办哪些活，见 [CPU 在干嘛](#/v3/08)）。多卡方案里，路由信息在卡间来回传导，每一纳秒的互联气泡（bubble，气泡=卡间互相等待的空闲时间）又雪球式累积进吞吐，卡越多，代价越可能吃掉容量优势。所以"显存比内存便宜，加卡就好"对大 MoE 不成立；类稠密模型（每步要动全部参数的模型，与 MoE 相对，如千问 27B）加卡收益线性，结论恰好相反。

> **案例（视频出处：BV1otY26LE8w）**
> "光是内部多卡之间的路由来回的信息传导，就完全可能会把你的显存容量优势、带宽优势完全给吃掉。"同一笔钱：类稠密模型上买卡是对的（2 卡>1 卡、4>2），两三百 B 级 MoE 上可能是反的。

统一内存赢在调度路径最短：模型碎片化程度低，CPU 与 GPU 之间是硬件级零拷贝，数据不用过总线（[统一内存与 offloading](#/v4/08)）。

## 哪些负载值得

- **值得**：200B 级以上大 MoE 的本地常驻。激活小所以带宽和算力要求低，总参大所以容量管饱，刚好是统一内存的形状；AIGC 这类高并行负载也吃这套硬件。
- **不值得**：27B 级类稠密模型，多卡直给更划算，别为它上统一内存。
- **要想清楚**：内存要按下一代买。DeepSeek V4.1 一个月内参数翻倍到五六百 B（其中约 200G 是 n-gram 外挂大表，见 [176B MoE + U盘](#/v5/05)），下一代 flash 模型起步可能 600B+，128G 很可能跑不动。先保证跑得起来，再关心快不快。

> **案例（视频出处：BV1otY26LE8w）**
> 容量门槛的刻度：395 的 96G 够放高精度千问 flash，跑 DeepSeek V4 flash 只能压到 IQ2 级低精度（IQ2：约 2 bit/参数的极低比特档）、把词表回落到硬盘；495 的 160G 可跑 GLM5.3-flash（智谱 GLM 系新一代大模型），更高精度的 IQ4 就放不下了（档位见 [INT8/INT4 与 GGUF 档位](#/v2/03)）。

## 怎么验证

- **查上限**：装机前在 BIOS 或系统设置里确认可分配显存（395 默认 96G、495 可到 160G），别拿内存总量当显存算。
- **算边际价格**：两台整机标价相减、除以内存容量差；结果明显高于同容量内存条单价（本例约 312 元/GB）时，优先考虑"两台小的"。
- **测带宽**：Linux 下跑内存带宽基准 `mbw 256`（mbw 是专测内存带宽的小工具）或 `sysbench memory --memory-block-size=1M --memory-oper=read run`（通用基准套件 sysbench 的内存项），读数应能摸到 200+GB/s 量级；再用 `llama-bench` 对比 `pp`（吞字）与 `tg`（吐字），应看到 pp 远大于 tg，直接印证带宽锁吐字。
- **先算装不装得下**：参数量 × 每参数字节（[显存三本账](#/v4/02)），这笔账永远排在速度讨论前面。
