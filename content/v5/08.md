## 一条除法就能拆穿的榜单

刷到过这种新闻吧：某模型"上周调用量世界第一"。有数字、有排名，看起来像体育赛事结果。UP 主的开场白更干脆："调用量世界第一？假的，全部都是假的。"这一章不评价任何模型，只拆这句话的**统计口径（metric）**：数字本身可能是真的，从数字到"世界第一"的推理是错的。

先做个类比：某公司食堂贴出"本周最受欢迎菜品榜"，数据真实、统计严格。但你能拿它宣布"全城最受欢迎的菜"吗？不能，样本只是这家食堂几百个吃饭的人。榜单类结论的第一问永远是：**这本账是谁的账本？**

### 账本只有一口锅：API 中转站

新闻引用的数据源是 OpenRouter（机器字幕常误写成"open router"）。它是一个国外的 **API 中转站**（API aggregator）：把各家模型的接口转发、聚合起来，统一计费，并不是什么权威统计机构。它的榜单只统计"经过它家转发的流量"这一个样本，属于[抽样偏差](#/v6/01)（sampling bias）：样本不等于总体。

再看指标本身。**调用量**（usage）= 一个时间窗口内消耗的 [token](#/v1/01) 总量；"周榜"就是窗口取 7 天。这个口径有个要命的特性：它计量的是 token，不是人。而 token 的消耗分布极端长尾：网页聊天的普通用户一天几百到几千 token，重度 API 用户一天能烧 20 亿，中间差着六到七个数量级。少数头部用户足以撬动整个榜单。

### 除法反推：刷一个第一要多少人

> **案例（视频出处：BV1kgN26SECZ）**
> 榜单：OpenRouter 过去一周第一名，调用量约 **6.13 万亿 token**。UP 主自称"中度偏重度"的 API 用户，单日最高用到 **20 亿 token**，一周约 **140 亿~150 亿**。

两个数一除：

| 数字 | 量级 | 含义 |
| --- | --- | --- |
| 6.13 万亿（6.13×10^12） | 周榜第一名的周消耗 | 榜单分子 |
| 150 亿（1.5×10^10） | 单个重度用户的周消耗 | 除数 |
| ≈ **409 → 约 400 人** | 6.13 万亿 ÷ 150 亿 | 刷到第一所需人数 |

UP 主的原话："你最少只需要 400 个我，就可以把你的模型冲到世界第一。"这种**数量级估算**（order-of-magnitude estimation）不需要精确数据：两个数量级相除，就能判断一个榜单数字"要多少人凑得出来"。

刷榜成本也随之显形：400 个重度用户一周的流量，就是 6.13 万亿 token 的 API 账单。按 token 计费（算法见[紧急刹车](#/v5/07)）是真金白银，但摊到一个中型团队或厂商自己的内部调用上，并不是天文数字。

### 用户量级 vs 调用量级

榜单只给 token，而衡量一个产品的真实规模，常用口径是活跃用户数。Claude、GPT、Codex、Claude Code 这些主流产品的用户量是**几百万级**（口径为 API/付费用户，不是注册总数）。400 人对几百万人，差 4 个数量级。一个 400 人样本刷出来的"调用量第一"，跟"用户量第一"根本不在同一个赛道。所以读任何榜单先问两个问题：这个数是**人的数量**还是 **token 的数量**？token 的样本来自谁的账本？

### 20 亿 token 一天，是怎么烧掉的

顺带解释那个反直觉的单日 20 亿。它不是人聊出来的：**Agent（智能体）**编程任务会把整个代码库塞进上下文反复读写，每一轮循环都重新读入大量历史与文件，上下文越长、调用越频繁，token 消耗按乘法增长（上下文的显存与成本代价见[上下文窗口与思考预算](#/v1/08)）。一个账号并发跑几十个长任务，一天烧掉 20 亿 token 并不神秘。反推一下：2×10^9 ÷ 86400 秒 ≈ 每秒 2.3 万 token 的平均速率，单机单并发达不到（tok/s 口径见[先会看表](#/v3/01)），但走 API 的多并发完全够得着。

账本没有错，错的是把小账本当成全网总账。数字为真、结论为假，这种情况在评测和榜单里到处都是。先问口径，再做除法，最后才信结论，这套动作在[七个方法论模式](#/v6/01)里叫"口径批判"。

## 怎么验证

- **复算刷榜人数**：

```text
python3 -c "print(6.13e12 / 1.5e10)"   # ≈ 408.7 → 约 400 人
python3 -c "print(2e9 / 86400)"        # ≈ 23148 → 单日 20 亿的平均速率（token/秒）
```

- **换算自查**：1 万亿 = 10^12 = 一万个亿。看到"万亿"先在心里换成"亿"再比大小，6.13 万亿 ÷ 150 亿 = 61300 ÷ 150，口算就能出 400。
- **看榜单字段**：打开 OpenRouter 的排行榜页（LLM Rankings），排名表按周给出每个模型的 token 用量。取当周第一名的数字，代入上面那条除法，结论应仍是"几十到几百个重度用户即可刷出"。
- **审读任何"世界第一"标题**：固定问三件事：数据源是谁的账本（厂商自报 / 第三方平台 / 全网统计）、统计窗口是日周月哪一级、样本规模与用户画像偏谁。三问里有一问答不上来，这个"第一"就先存疑。
