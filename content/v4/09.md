## 装机收尾的三笔账：平台、功耗、电费

显卡怎么选，前面几章已经讲完，但卡不会单独干活。一台推理机 = 平台（CPU+主板+内存）+ 电源 + 显卡 + 一只天天在走的电表。类比买车：发动机（显卡）再强，也得看车库门宽不宽、油箱够不够、油价划不划算——分别对应平台的 PCIe 通道、电源功率、电费。这三步新手最容易跳过，也最容易翻车。

### 平台：消费级的通道数，够谁用

PCIe lane 的账在 [NVLink 与 PCIe 全家桶](#/v4/07) 已经算过：x16 直连 CPU 那条最值钱，其余插槽多半挂在南桥后面。消费级主板只有一条 x16 直连，插第二张卡就要拆分或绕南桥，第三张更挤。服务器平台是另一番景象：EPYC（霄龙，AMD 的服务器 CPU 线）7002/7003 最多给到 128 条 PCIe 4.0，每张卡都能 x16 直连，卡间 P2P 也顺畅。

> **案例（视频出处：BV1hLtG6ZE5M）** 谈多卡方案时 UP 主把平台放在卡前面："如果说你的主板支持多个 PCIe，比如像这个 EPYC 的，霄龙的 7002、7003，就有可能 128 条非常高速的 PCIe 4.0"。反过来，靠 PLX 拆分卡（如 PEX88096）硬凑通道，卡本身的短板（比如不支持 P2P 点对点拷贝）反而被放大——多卡能不能 1+1=2，先看平台给了多少车道。

### 迷你主机改装：500 元的 M720q 凭什么带三张卡

另一个极端是省钱路线：拿 1L 迷你主机（机身体积约一升）联想 M720q Tiny 当主机，配 i3-9100T，4 核 4 线程，TDP 35W。CPU 核心与线程在推理里到底干什么，[CPU 在干嘛](#/v3/08) 已算过账：个人低并发场景，CPU 够用就行。

TDP（Thermal Design Power，散热设计功率）要单独说清：它是散热器按多大功率排热设计的参考值，不是电表读数。实际功耗随负载浮动，通常低于 TDP，整机还得把内存、硬盘、主板的份加回去。UP 主那句反话——"4 核 4 线程的高功耗 CPU，功耗高达 35 瓦，所以性能非常强劲"——正是拿来教你识破参数话术的。

改装的关键不在 CPU，在通道引出：riser 转接卡把 x16 拆成 x8（直连 CPU）加 x4（南桥桥接），M.2 口再转出 x1，两张 2080Ti 分别挂 x4 与 x1 并用 NVLink 互联，省下的 x8 引出给第三张卡——1L 机身塞进三张卡。通道怎么拆、为什么这样能通，见 [v4/07](#/v4/07)。

> **案例（视频出处：BV12ZEN6CEho）** 这套方案的预算观："我们要把更多的预算留给我们的服务器，留给我们的主机"——两张魔改卡 3500 元，主机约 500 元；上 2×8G DDR4 2400MHz 双通道内存后整机 600~700 元。内存不能省：模型本体要先住得进内存（见 [显存 vs 内存](#/v4/01)）。

### 功耗预算：从 500W 加到 1100W

功耗预算是道加法题：整机功耗 ≈ 各卡功耗之和 + 主机余量。

| 部件 | 估算 |
| --- | --- |
| 2080Ti 22G ×2 | 约 500 W |
| 主机（CPU、内存、硬盘、主板） | 约 100 W |
| 整机合计 | 约 600 W |

电源不能按 600W 买：模型加载、并发突增时有瞬时峰值，电源高负载下转换效率下降、元件老化后余量缩水，惯例按 1.5 倍以上留冗余——于是 600W 整机配 1100W。电源可以是服务器拆机件：戴尔 1100W 拆机价 60 元，接口需自行改造。

> **案例（视频出处：BV12ZEN6CEho）** "两张 2080Ti 加一起功耗已经高达了 500 瓦……整体功耗可能高达 600 瓦"，而且"功耗当然没有 5090 一张那么高"——双老卡未必比单新旗舰费电（对比对象是两张卡合计 500W，不是整机 600W）。电源要"服务器级别的电源，最好是 1100 瓦以上"，UP 主用的正是那颗"花费高达 60 块钱"的戴尔拆机件。

### 电费算术：一天满载能产出多少 token

最后把功耗换算成产出和钱。日产出只看 decode 速度（口径见 [先会看表](#/v3/01)）：

`日产出 token = 3600 × 24 × 实测 tok/s`（一天共 86400 秒）

100 tok/s 满打满算约 864 万 token/天（含 MTP 的峰值口径）。电费那边：电量（度）= 功率（kW）× 时间（h），600W × 24h = 14.4 度，按民用电价 1~1.4 元/度算约十几到 20 元/天。两个数字一除，得到一个很少有人算的比值：每 20 元电费，换约 864 万 token。

> **案例（视频出处：BV1KKE96CELt）** UP 主的算法："3600 秒乘以 24，然后每秒再乘以 100……那也就才 800 多万 token，一天满打满算全部拉满"；电费"可能就要 20 块钱啊，十几到 20 块"。而某国产大模型 flash 档的正式价是每百万输出 token 2 元——同样 20 元能买 1000 万输出 token，超过本地满载一天的极限产出，结论是"用了一个更贵的价格，去用一个更弱的模型"。算上硬件折旧、真实利用率与矿卡风险的完整账本，在 [紧急刹车：本地 vs API 的 TCO](#/v5/07)。

电费的另一面是"每瓦换多少性能"，即能效比，选卡时怎么用它见 [显卡市场生存指南](#/v4/10)。

## 怎么验证

- **对照 TDP 与实际功耗**：`nvidia-smi --query-gpu=name,power.draw,power.limit --format=csv`，`power.draw` 是瞬时实测功耗，`power.limit` 是卡的功率上限；CPU 侧用 `lscpu` 看核心/线程数，封装实际功耗可用 `turbostat`（内核自带的读 CPU 实际功耗工具）读——体会 TDP 不是电表读数。
- **量整机墙插功率**：接一个计量插座，跑 `llama-bench -m 模型.gguf -p 2048 -n 128` 时读满载功率，对照上文 600W 的量级，再核对你电源的冗余倍数。
- **算你自己的电费与产出**：日电量 = 实测功率（kW）× 24h；日电费 = 日电量 × 电价（电费单上有）。日产出 = 你实测的单并发 TG × 86400 秒；电费 ÷（日产出 ÷ 100 万）= 本地每百万 token 的电费成本，拿去和 API 单价直接比。
- **查平台通道**：`sudo lspci -vvv | grep -E 'LnkCap|LnkSta'` 看每张卡协商到几条 lane、哪代 PCIe；`lspci -t` 打印拓扑树，谁直连 CPU、谁挂在南桥（PCH）下一目了然——多卡方案动手前先做这一步。
