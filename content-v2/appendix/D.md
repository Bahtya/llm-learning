# 附录 D · 进阶篇入口

以下主题对部署决策有影响，但超出入门主线，规划进阶篇展开：

- **CUDA vs ROCm 生态账**：AMD 卡跑大模型的软件栈现状、HIP/SYCL 路线、选卡前的生态核查清单（正文 5.2 的"先查 ROCm 支持再掏钱"是结论，机制在此展开）
- **软件栈四层**：驱动 → 运行时 → 算子库 → 框架，缺一层打对折的实例
- **张量核心三代演进**：V100/Turing/Ampere 的指令与数据排布差异，DP4A 与 cp.async 的角色
- **CPU offload 进阶**：层卸载与张量卸载的实现差异、mmap 行为

写法沿用正文契约；每篇配可复现实验。
