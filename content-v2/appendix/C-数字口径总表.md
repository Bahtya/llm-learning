# 附录 C · 全书数字口径总表

同一件事在不同章出现不同数字，多数不是矛盾而是**口径不同**。本表把全书反复出现的数字按口径排列，供对照自查。

## 27B 级模型 Q4 档的体积（四个口径）

| 口径 | 数值 | 出处/含义 |
|---|---|---|
| 纸面下限 | 13.5G | 27B × 0.5 字节（数学值，不含任何开销） |
| 超级块账 | ≈15.2G | 按 4.5bit/权重 + 结构开销（2.4） |
| 标注口径 | 16.5G | Q4_K_M 实际文件（含 _M 混合升格与词表，2.4） |
| 项目实测 | 20 多 G | AWQ INT4 路线（BV1UMEv68E3C，2.2/4.4） |
| 口播转述 | 约 25G / 17G | 个别视频口播（4.1/4.2、5.2），以模型卡为准 |

**decode 理论上限随口径联动**：616GB/s ÷ 16.5G ≈ 37 tok/s（单卡 Q4_K_M）；双卡聚合 1.2TB/s ÷ 20 多 G ≈ 60 tok/s（4.1）。实测低于理论上限属正常（见 3.4）。

## 8B 级模型的 KV 单 token 值（两个口径）

| 口径 | 值 | 说明 |
|---|---|---|
| 教学假设 | 128 KiB/token | 按 32 层假设（1.3/1.4/3.2/3.3 的算例口径） |
| qwen3:8b 实际 | 144 KiB/token | 36 层（官方 config.json，2.1 修正口径） |

## 千问 27B 的 KV 翻案账（256K 上下文，FP16）

| 口径 | KV 体积 | 前提 |
|---|---|---|
| naive | 64 GiB | 64 层全部按全注意力 |
| Layer type 修正 | 16 GiB | 仅 16 层全注意力（模型卡字段，2.1/5.4） |
| Gemma 对照 | 120G → 20G | 60 层中 10 层全注意力 |

## 双 2080Ti（22G 魔改 ×2）实测行

| 指标 | 数值 | 口径 |
|---|---|---|
| Prefill 单卡 | 580 tok/s | 27B Q4_K_M、8K 拆 4×2K |
| Prefill 双卡 PP | 800 多 tok/s（口播 +50%，整数算 +38~50%） | 同上，20+20 层接力 |
| Decode 裸 | 约 50 tok/s | 不开 MTP；带宽理论上限约 60 |
| Decode 开 MTP | 90~100 tok/s | 同机开 MTP |
| Prefill（INT8 疯狗模式） | 2500（纯文本）/ 2600（代码） | 另一档位与模式的对照 |
| 显存合账 | 44G = 20G 权重 + 16G KV + 约 8G 缓冲 | 256K FP16 KV 口径 |

## 成本口径

| 项 | 数值 | 条件 |
|---|---|---|
| 满载产出 | ≈864 万 token/天 | 100 tok/s × 86400s（含 MTP 峰值口径） |
| 电费 | 14.4 度/天 ≈ 14~20 元 | 600W × 24h，1~1.4 元/度 |
| 本地每百万 token | 2.3/η 元 | η=利用率；η=20% → 11.6 元 |

## 单位口径

GB/GiB 相差约 7.4%：KV 账按 1024³（GiB），权重商品口径按 10⁹（GB）；`nvidia-smi` 显示 GiB。TFLOPS/TOPS 分属浮点/各厂自定义口径，不互相换算（2.3）。
