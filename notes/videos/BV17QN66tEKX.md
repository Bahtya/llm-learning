## 知识点候选

- FLOPS / TFLOPS / TOPS 是什么、如何比较算力 ← 二进制数量级（T=10^12）
- 浮点数表示（尾数/指数位宽决定精度与动态范围）← 二进制
- FP32（单精度）与 FP16（半精度）的区别，以及为何半精度算力通常更高 ← 浮点数表示
- TF32：NVIDIA 在安培架构引入的"19 位截断"混合格式，Tensor Core 专用 ← 浮点数表示、Tensor Core、安培架构
- 矿卡（CMP 系列）与游戏卡 / 数据中心计算卡的产品线差异 ← NVIDIA 产品线、挖矿史
- NVIDIA 对矿卡的算力/显存限制在哪个层面实现（驱动、固件、熔丝位）← 矿卡概念、固件与驱动分层
- "改算子"绕过限制是什么意思 ← CUDA 算子/内核概念、软件栈分层
- GA100 核心与 A100 的关系：同一颗大核心按良率"刀法"切割出不同 SKU ← 芯片制程、良率、SKU 策略
- HBM 显存：与 GDDR 的区别（堆叠、超宽位宽、靠近核心）← 显存类型、内存带宽
- 显存容量为何能被"屏蔽/解锁"：颗粒物理在位、固件关闭部分堆栈 ← HBM、固件
- 显存容量对本地大模型的决定性意义：权重必须装得下，80G 意味着能跑更大的模型 ← 模型参数量与显存占用估算
- 算力（TOPS）与显存容量谁才是本地推理瓶颈 ← 推理的访存受限本质
- 二手矿卡市场的价格机制与"踏空"风险 ← 矿卡生态、供需
