- 输出 token 与输入 token 的价格差异 ← API 计费模式
- MoE（混合专家）：总参数量 vs 激活参数量 ← 模型参数量；稠密模型；前向计算只走部分专家
- "参数量越大性能越强"的经验规律及其与激活量的区别 ← MoE 参数量/激活量

## 金句与案例

- **【案例1：本地一天产出算术】**（第22-31段）：以 100 tok/s 为例，3600 秒 × 24 小时 × 100 tok/s ≈ 864 万 token/天，"一天满打满算全部拉满"也就这个量级——这是后续一切成本对比的基准数字。
- **【案例2：电费锚点】**（第32-36段）：显卡 24 小时满载电费"十几到 20 块/天"，即每月约 400-600 元，什么都不干也在烧钱。
- **【案例3：API 价格锚点】**（第39-52段）："国产之光 Lipstick v4 flash"正式价每百万输出 token 2 元；于是 20 元电费 = 1000 万输出 token > 本地一天 864 万 token 的极限产出——电费换 API 反而赚。
- **【案例4：核心翻盘金句】**（第58-60段）："我们用了一个更贵的价格，去用一个更弱的模型"——本地推理成本账的总判决，可作书中"要不要本地部署"章节的标题级结论。
- **【案例5：隐性成本清单】**（第54-57段）：前期硬件搭建精力 + 购买成本 + 二手显卡质量风险，三项在电费对比里都还没算。
- **【案例6：社区热度佐证】**（第2-10段）：项目上线一周 100 star、私信被拉爆，问的全是"显卡去哪买/哪家店靠谱/2080ti vs 3090 vs 5090 怎么选"——说明"先买卡再想用途"是新手普遍路径，正是本视频要刹车的点。
- **【案例7：性能对比锚点】**（第44-48段）：V4 flash 总参数量远大于 27B（激活量未必更大），性能一定强于 27B——同时给出"更大参数的 API 反而更便宜"的结论，构成对本地 27B 方案的双重打击。
