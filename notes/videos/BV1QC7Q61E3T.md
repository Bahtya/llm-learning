## 术语穷举

- **2080 Ti（RTX 2080 Ti）**："两张2080ti加一起3500块钱"——本视频的主角硬件，双卡组合。
- **双卡 / 两张卡**："两张2080ti跑起来了"——27B FP8 单卡放不下，靠双卡分摊。
- **二手矿卡**："3500块钱这样的一个二手矿卡"——价格便宜但来路是矿场退役卡。
- **Qwen 27B（字幕"千万27"，标题作 Qwen3.6 27B）**：被测模型，27B 参数稠密模型。
- **27B（字幕"R 7b"）**："27B FP8，5090 你都塞不下"——参数规模表述。
- **FP8（字幕"lp8"、"B lp8"）**："27B FP8 权重"——8 位浮点量化格式，本视频测的权重精度。
- **INT4（字幕"IT4"、"IT4上次我们测过"）**："比我们之前测过的INT4稍微慢一点"——4 位整数量化，此前视频的对比项。
- **全量权重（字幕"全重"）**："全重"——指非截断/非部分量化的完整权重部署方式（转写残缺，疑还夹带"128"字样，或指 128K 上下文/权重体积，无法确证）。
- **KV 缓存（字幕"KFP16圆"→"KV FP16 原"）**："KV FP16 原精度上下文"——本次测试 KV 缓存保持 FP16 原始精度，未做量化。
- **FP16**：同上，KV 缓存的数据精度。
- **上下文**："精度上下文"——与 KV 缓存精度绑定的上下文配置。
- **token（字幕"Token"、"抽肯"）**："80多token每秒"——生成速度的计量单位。
- **tok/s（每秒 token 数）**："80多token每秒每秒80多"——解码速度指标。
- **Decode / 解码速度**："这样的一个解码速度"——逐 token 生成的阶段速度。
- **Prefill / 预填充（字幕"prefu1600"、"PREFI"）**："Token prefill 1600"——吃入输入（提示词）阶段的吞吐速度。
- **显存（隐含）**："5090 你都塞不下"——模型权重+KV 缓存超出单卡显存容量。
- **RTX 5090（字幕"5090"）**："5090 你都塞不下"——作为显存容量参照的高端卡。
- **vLLM（字幕"V l m"）**："来关注这个项目啊，vLLM 2080Ti definitive"——UP 主维护的推理项目（让 2080Ti 这类老卡跑 vLLM/FP8）。
- **项目版本 0.1.4**："我们项目现在已经更新到了0.1.4"——该项目当前版本号。
- **速度可用性（经验判断）**："现在的这个速度已经是非常非常可用了"——对 80 tok/s 档位的主观评价。

## 知识点候选

- token ← 分词器（tokenizer）、文本的最小单位
- tok/s（解码速度）← token、自回归生成
- Decode 解码阶段 ← token、自回归生成、KV 缓存
- Prefill 预填充阶段 ← token、注意力机制
- 浮点数表示（FP16 / FP32）← 二进制、计算机数值表示
- FP8 量化 ← 浮点数表示、量化（精度 vs 显存/速度的取舍）
- INT4 量化 ← 量化、整数表示
- 权重全量部署（"全重"）← 模型权重、参数量
- KV 缓存 ← 注意力机制、Decoder 架构
- KV 缓存精度（KV FP16 原精度 vs 量化 KV）← KV 缓存、浮点数表示
- 参数量 → 显存占用估算（27B FP8 ≈ 27GB+，KV 缓存另算）← 参数量、FP8、KV 缓存
- 显存容量墙（为何 5090 单卡装不下 27B FP8 + FP16 KV）← 显存估算、KV 缓存、上下文长度
- 双卡推理（多卡分摊显存，隐含张量并行/流水线概念）← 显存容量墙、模型切分
- GPU 架构代际（2080 Ti 为 Turing/SM75 老架构，不原生支持 FP8）← GPU、CUDA、SM 版本
- 老卡跑新精度格式的软件方案（vLLM 2080Ti 项目）← vLLM、GPU 架构、量化
- vLLM 推理框架 ← 推理引擎、KV 缓存、批处理
- 二手矿卡的价格与风险 ← 硬件市场常识
- 上下文长度与 KV 缓存占用的正比关系 ← KV 缓存、上下文
