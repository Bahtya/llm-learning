## 知识点候选

- token 与逐 token 生成 ← 语言模型基本工作原理
- 自回归解码（一个一个吐 token）← token
- Prefill（预填充/吞字）与 Decode（解码/吐字）两阶段 ← 自回归解码
- 吞吐量与 tok/s、输出速度的恒定性 ← Prefill/Decode
- 稠密模型（Dense）与"类稠密模型" ← Transformer 基本结构
- FFN 层（前馈层/专家层）与注意力层 ← Transformer 结构
- MoE（混合专家）模型 ← FFN、稠密模型
- MoE 路由器与专家调度 ← MoE
- 总参数量 vs 激活参数量 ← MoE
- n-gram 概念与 n-gram 查询表"外挂"（新 MoE 架构的大表） ← MoE、n-gram 语言模型
- 权重文件大小 ≈ 参数量 × 每参数字节数（500G 权重、600B 参数的量级感） ← 参数量、量化
- 存储层级：显存 / 内存（统一内存）/ 硬盘 ← 计算机组成基础
- 内存带宽（GB/s）与 Decode 速度的带宽瓶颈关系 ← 存储层级
- 算力（FLOPS/TOPS）与 Prefill 速度的关系 ← 浮点运算
- 浮点数表示：FP32 / FP16（半精度） ← 二进制、科学计数法
- 低精度格式：FP8 / FP4 / NVFP4 / INT8 ← 浮点数表示
- 融合算子模拟低精度 vs 硬件原生低精度矩阵单元 ← FP16、算力
- 量化：GGUF 的 IQ1/IQ2/IQ4、NVFP4 量化、极限量化 ← FP16、权重文件大小
- 词表/embedding 回落硬盘（offload） ← 存储层级、模型文件构成
- 多卡方案与显存堆叠（力大砖飞） ← 显存、模型显存占用
- 张量并行 ← 矩阵乘法、多卡
- 卡间互联总线：PCIe / NVLink / ConnectX-7+光模块 / USB4 ← 总线与带宽概念
- 通信开销与流水线"气泡"、雪球效应 ← 张量并行
- 投机解码（draft-verify 思想） ← 自回归解码
- MTP（多 token 预测）、DFlash 等投机解码实现 ← 投机解码
- 置信区间/方差概念（速度数据波动大） ← 基本统计
- 统一内存架构（CPU/GPU 共享同一物理内存） ← 内存、显存
- 零拷贝与 PCIe 数据搬运瓶颈 ← 内存拷贝、总线
- 集显 + 共享内存的 BIOS 固定划分 vs 统一内存动态热分配 ← 集显、BIOS
- CPU 参与 MoE 调度带来的主机级要求（节点时延） ← MoE 路由
- CPU 缓存层级与寄存器（L1-L4）对 CPU-GPU 时延的意义 ← CPU 架构
- GPU 架构代际：RDNA3 / RDNA3.5 / RDNA4；Ampere → Blackwell（30/40/50系） ← GPU 基础
- GPU 软件生态：CUDA vs ROCm 的优化差距 ← GPU 编程生态
- x86 与 ARM 指令集差异及软件兼容性（Windows on ARM、Ubuntu ARM） ← 指令集概念
- ANE/NPU 与 TOPS 指标 ← 算力、INT8
- 推理框架与社区版本复现（llama.cpp、losebox、hello-flash） ← 推理框架概念
- AIGC 负载与 LLM 推理负载对算力/带宽需求差异 ← 算力、带宽
- 价格锚点思维：每 64G 内存/每 TFLOPS 的边际价格比较（395 vs 495 的 2 万元买什么） ← 上述全部
