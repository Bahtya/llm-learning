- **tokens/s（tok/s、tk/s）**：解码速度单位，"每秒100以上 tokens"

## 知识点候选
- token 与 tokens/s（解码速度指标）← 大模型自回归生成（一次前向输出一个 token）
- 27B 参数量与显存需求 ← B=十亿参数、参数量×每参数字节数≈权重体积
- 稠密模型（dense）vs MoE ← Transformer 基本结构、前向计算路径
- 显存（VRAM）vs 内存（RAM）← 计算机存储层级
- 魔改显卡（2080Ti 22G 的来历与风险）← RTX Turing 架构、显存颗粒更换/翻新卡
- NVIDIA 显卡世代（20系/30系）← RTX 命名与架构代际
- CPU 规格：核心/线程/TDP（i3-9100T 35W）← CPU 基础、TDP 不等于实际功耗
- DDR4 笔记本内存（SO-DIMM）、双通道、频率 2400MHz ← 内存通道与带宽概念
- 1L 迷你主机（ThinkCentre Tiny 系列）的扩展性限制 ← 主板形态/ITX
- 功耗预算与电源功率：500W 双卡+整机 600W → 1100W 电源冗余 ← 电功率、电源转换效率、瞬时峰值
- 服务器拆机电源（戴尔 1100W）及其改造接法 ← 电源接口/ATX 标准
- PCIe 通道与版本带宽：PCIe 3.0 下 x1/x4/x8 各是多少 GB/s ← 总线概念
- CPU 直连通道 vs 南桥（PCH/芯片组）通道 ← 主板拓扑（南北桥历史）
- PCIe 通道拆分（bifurcation）与 Riser 转接卡 ← PCIe 通道概念
- M.2 接口的本质就是 PCIe/NVMe 通道 ← M.2 物理形态 vs 协议
- NVLink 卡间互联 ← 互联带宽对比 PCIe、为什么要绕开 PCIe 瓶颈
- GPU P2P 通信（peer-to-peer 显存直访）← NVLink、多卡显存池化
- 多卡推理的张量并行（TP，隐含背景）← 模型切分、卡间通信需求
- 本地推理 vs 云端 API 的能力差距 ← 推理服务、模型规模差距
- 性能优越感/跑分文化（赛博斗蛐蛐）← 本地部署社区生态
