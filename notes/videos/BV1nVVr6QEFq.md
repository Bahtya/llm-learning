# BV1nVVr6QEFq 两张2080Ti跑27B稠密模型，单并发近100 tok/s，立省5万（vLLM 2080Ti 项目发布）

> 视频时长约 1.5 分钟（49 段字幕），属于"项目发布 + 现场实测"型短视频。
> 核心内容：UP 主发布自己魔改的 vLLM 项目（vLLM-2080Ti definitive），用两张二手 RTX 2080Ti + NVLink 桥 + 500 元廉价主机（总价约 4500 元）跑 Qwen 27B 稠密模型，现场以"生成网页版 FPS 游戏（还迭代加钓鱼模式）"做压力演示，单并发 decode 速度 80~100 tok/s，并锚定"一张 RTX PRO 6000（约5万元）也不过这个速度"。

## 术语穷举

- **2080Ti（RTX 2080 Ti）**：核心主角卡。原文"两张2080ti加一起"；另一处转写错误"两张808""2080赛"均指 2080Ti（Turing 架构二手卡）。
- **双卡 / 两张卡**：'"两张2080ti"——用两块消费级旧卡拼出足够显存与算力。
- **NVLink**：卡间高速互联，字幕转写为"mv link"（"再加上mv link"），即 NVLink 桥接器。
- **500块钱的主机**：除显卡外的整机（CPU/主板/电源等），"再加上500块钱的主机"。
- **4500 元**：整套方案总价锚点："可能就4000多块钱 4500块钱"。
- **立省5万**：与专业卡对比省下的钱："立省起码5万块钱"。
- **27B 稠密模型**：所跑模型的参数量与结构，字幕转写为"前文27"（校正：千问/Qwen 27B），标题明确"27B稠密"。
- **稠密（dense）**：模型结构类型，每个参数都参与每次前向（区别于 MoE），见标题"27B稠密"。
- **Qwen / 千问 / 阿里**："两张阿里曼带模型 前文27好"——校正为"两张2080Ti 带阿里（千问 Qwen）27B 模型"。
- **token**："100tokens"，模型生成的最小单位。
- **tok/s（tokens per second）**：生成速度单位，标题"单并发100tok/s"，字幕"100tokens""100抽肯每秒"（校正：token 每秒）。
- **单并发**：标题术语，batch=1（只有一个用户请求）时的 decode 速度，本视频的全部测速都在此场景。
- **decode 生成速度（90多、接近100）**：现场口播数速："你速度多少 90多了""接近100"。
- **vLLM**：推理引擎，项目基础："这个VLLM2080ti definitive"——UP 主为 2080Ti 魔改的 vLLM 版本。
- **vLLM-2080Ti definitive（项目仓库）**：UP 主公开的仓库名："大家可以到我的这个仓库里面去看一下…这是我项目"。
- **RTX PRO 6000（pro6000）**：专业卡对比对象："你可能买了一张pro6000 可能也就是这个速度"（约5万元级工作站卡）。
- **显卡价格雪崩**：UP 主对二手卡市场的影响预测："这个项目一旦上线 显卡价格可能会雪崩"。
- **网页版 FPS 游戏**：压力演示任务——让模型现场生成一个浏览器可玩的 FPS 游戏："来让他跑一个生成一个网页版FPS游戏"。
- **代码生成（HTML/前端代码）**："他已经在深渊更好代码"（校正：生成 HTML 代码）——模型持续输出前端代码。
- **钓鱼模式**：对已生成游戏的迭代需求："我们要增加…鱼模式来增加钓鱼模式"——展示多轮改代码能力。
- **"321走"（数速环节）**：口播倒数后现场读速度计，属于演示形式而非技术名词，但对应"实时测速"这一行为。
- **仓库（GitHub repo）**：项目发布渠道："可以到我的这个仓库里面去看一下"。
- **跑车（比喻）**："两张100 token每秒在跑的是他在跑车"——形容速度感，非技术词，列出以示穷举。

## 知识点候选

- token 与生成速度 tok/s ← 自回归逐 token 生成
- decode 阶段与 prefill 阶段的区别 ← token、KV 缓存
- 单并发（batch=1）为什么是"个人使用"最真实的速度指标 ← decode、并发/batch 概念
- 27B 参数量意味着多少显存、多少算力 ← 参数量、显存、权重量化
- 稠密模型 vs MoE：为什么 27B"稠密"对小显存双卡是硬仗 ← 参数量、稀疏激活
- 双卡跑一个模型：张量并行（TP=2）如何切分 ← 模型层/权重切分、卡间通信
- NVLink 与 PCIe：卡间带宽对双卡推理的影响 ← 张量并行、PCIe 带宽
- Turing 架构 2080Ti（SM75）为什么能跑现代 vLLM：软件适配/量化路径 ← GPU 架构代际、vLLM、量化
- vLLM 是什么：PagedAttention、KV 缓存管理 ← KV 缓存、推理引擎
- 显卡价格锚点：2080Ti 二手价 vs RTX PRO 6000 约 5 万 ← 显卡产品线定位、二手市场
- "价格雪崩"逻辑：软件突破如何让旧卡需求暴涨 ← 供需、性价比锚点
- 用"生成可运行网页 FPS 游戏"作为推理能力压测的原理（长输出、代码结构约束）← LLM 代码能力、前端基础
- 多轮迭代改代码（加钓鱼模式）对上下文长度与一致性的要求 ← 上下文窗口、多轮对话
