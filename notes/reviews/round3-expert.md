# 专家评审 · 知识正确性（第 3 轮）

覆盖全部 46 章（v1–v6），重点细查 v2/v3/v4 的机制表述，并与 `notes/videos/` 22 份笔记逐条对照；另用公开资料复核了本轮争议数字（CUDA 13 架构支持、CMP 90HX 规格、Apple M5 精度支持、Intel A770 算力口径）。

## 总评

第 2 轮的修复整体落地且方向正确：Gemma 31B 全书统一为"视频口播、代际待核"、TP worker 三处改对并顺手标注了 UP 主口播的 CPU 视角、P40+P106 四处口径一致、MTP 口径在 v1/08、v3/03、v3/05、v5/01、v5/07、v6/01 均已补、统一内存"物理统一/零拷贝"与"动态划线仅苹果系"的两层区分写得比上一版准确、投机解码严格式 1.25 与线性上界 1.8 的并置也对。但本轮发现三处**由修复本身改出的新错误**：v4/04 把"只支持到 CUDA 12"从 V100 错误推广到 2080Ti（图灵恰是 CUDA 13 仍支持的最低代，且与 v3/09 自相矛盾）；v4/10 把 90HX 写成"常见完整的 x16"（源笔记与公开规格都是出厂锁 PCIe 1.0 x4）；v5/04/v4/05 把 90HX 显存统一成 GDDR6（视频与 TechPowerUp 均为 GDDR6X、约 760GB/s）。另有若干**同族漏改**（GDN 译名只改了词条、V100 130T 只改了两处、v3/01 这个专讲口径的章节反而漏了 MTP 注、v5/03 的线性上界与颜色指代未跟上 v3/06）。机制层面 v2/v3/v4 的核心表述（浮点位分配、weight-only 与 Marlin、PagedAttention 分页与抢占、CUDA Graph 捕获/回放与显存代价、TP all-reduce 129 次与 payload 公式、PP/TP 对互联的不同敏感度、roofline 两段式）全部复核通过，算式复算亦无发现新错。

### 本轮复核通过、未发现问题的重点

- v2 卷机制全部成立：E4M3=448 / E5M2=57344、NVFP4 每 16 元素 FP8 scale + 张量级 scale、FP8 消费卡起点 Ada（数据中心 Hopper 更早）、`get_device_capability` 的 (7,5)/(8,9)/(12,0)、图灵跑 FP8 靠 Marlin 反量化、W8A16/W8A8 命名、per-channel/per-group 与 scale 开销 3% 复算（1677 万数 / 8.4MB / 131072 个 scale）、KV 三档 64/32/16G 与"naive 口径"声明、`-ctk/-ctv` 与 `--kv-cache-dtype`。
- v3 卷机制全部成立：PagedAttention 128KB/token、32K=4GB、浪费 <4%、利用率两到四成、默认块 16、抢占=重算或换出；CUDA Graph 500×5µs=2.5ms/10ms、`--enforce-eager`/`--disable-cuda-graph`；投机解码严格式 p=0.2 → 1.25；TP worker=每卡一个分片进程（并正确标注了 UP 主口播的 CPU 视角）；`llama-bench` 的 `-sm layer/row`、vLLM 的 `--pipeline-parallel-size/--tensor-parallel-size`；V100 停在 CUDA 12、gfx906、ROCm 支持状态。
- v4 卷算式复算无误：payload 2048×5120×2=20MB 与 4096 时 42MB×129≈5.4GB、64K 时≈87GB；decode 129 次=每层 2 次×64 层+1；2080Ti 616GB/s÷16.5G≈37 tok/s；KV 44G=20+16+8；EPYC 7002/7003=128 条 PCIe 4.0；NVLink 2.0 双向 100GB/s≈6×PCIe 3.0 x16；PCIe 1.0~5.0 每 lane 250MB/s~4GB/s；600W×24h=14.4 度。
- 对照笔记的忠实度良好：M3 Ultra"Prefill 比不过 1080Ti"确出自 BV1GtbL63Ekt（非 BV1otY26LE8w，引用章正确）；hello-flash 200~300→1000+、DGX Spark 3000+ vs 395 900+、AI Max 495（8065S/192G/160G/4 万）、hello-flash 与 900+ 两组数字"口径不同不互算"的声明、176B=125B+51B 与 21G/51G 拆账、P40+P106、170HX 0.3T/31 倍/100 TOPS 的口径拆分、投机解码三方案的厂商归属与 PP 兼容坑，均与源笔记一致。
