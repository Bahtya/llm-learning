# v2 评审 · CS 学生

评审人设定：计算机专业大三，学过组成原理（cache/总线/IEEE754），没玩过显卡、没用过推理框架。逐章 Read 全部 23 章（part1~part5），只查可懂性与一致性，不评代码与 assets。

## 总评

全书主线（部署→链路→显存→测量→瓶颈→量化并行→多用户→选型成本）对我这种只会组成原理的人非常友好：位段解剖接住了 IEEE754 旧知识，三层存储/带宽接住了 cache 层级，术语几乎全部先行定义并附英文，"口径声明＋误差来源"的格式让我敢信每个数字。我抽算了 1.3、1.4、2.1、2.4、2.5、3.1、3.2、3.4、4.1、4.2、4.3、4.4、5.1、5.3 的章末完整算例，绝大多数条件给全、数值互相咬合（144 字节=4.5bit、129 次 all-reduce、352×14÷8=616GB/s 等都能独立复算）。主要问题集中在跨章数字口径：8B 的 KV 单 token 值在第一部分（128 KiB）与第二部分（144 KiB）并存且未正式互认，27B Q4_K_M 体积全书出现 16.2/16.5/17/25G 四个数，个别算例（5.2 的 KV 账、1.2 的 27B INT8 单卡）与本书自己立的账本对不上。"指标回看"与章末衔接的兑现率很高，仅两处回指落空（GQA、多卡切分的章号）；建议卷末加一张"全书数字口径总表"。
