## 验收结论（通过）

全书可以一次顺读到底，没有一处让我"彻底卡死"。每章都是"直觉类比 → 术语定义 → 算账 → 视频案例 → 怎么验证"的固定结构，前向引用一律带路标（"下一章讲""细节见 vX/NN"），需要本地环境的验证小节统一标了"没有环境可跳过，不影响后续阅读"。我把书里能复算的数字账几乎全部重算了一遍——KV 的 64G→16G/120G→20G、softmax 三档温度表、8B 模型每 token 128KB 与 32K=4G、TP 的 129 次 all-reduce 与 42MB/87GB payload、27B 权重三口径对照、176B 的 3.3bit/1.3bit 位宽账、395→495 的 312 元/GB、TCO 的 864 万 token 与利用率三档表、6.13 万亿÷150 亿≈409——全部自洽，没有发现对不上的账。四项重点修复点均稳定：v1/01 同时有"推理=inference"的定义和"先查术语速查表"的路标；KV 翻案的完整计算只出现在 v1/06（及其案例章 v5/02），前文只留悬念；裸 decode 口径全书一致（裸≈50 / 带宽理论上限≈60 / 含 MTP 90~100，TP 50→100）；170HX 的"0.3 TFLOPS / 31 倍 / 100 TOPS"在 v2/01、v4/05、v4/10 三处都做了口径隔离并保留视频原话的存疑声明，CUDA 13（图灵为最低支持、Volta/Pascal 停在 12，v3/09/v4/04/v5/04 三处一致）与 90HX（10G、GDDR6X 320bit≈760GB/s、PCIe 锁 1.0 x4）也干净。遗留 6 条均为低严重度，不构成再修一轮的必要理由，可作为随手清理项。
