## 验收结论

**通过。** 这是我第一次靠自己把一本讲推理底层的书从头读到尾：每个黑话第一次出现都有括号白话解释或"见 x 章"跳转，第 1 章开头就告诉我"看不懂先查术语速查表、'怎么验证'没有环境可以跳过"，这两条保命规则贯穿了全书，我一路没有出现"这个词完全没画面、只能硬着头皮往下翻"的死点。把我放回看 SPOTLITE 视频的场景，验收指定的六个卡壳词全部能对上号，而且对上的是"画面"不是"定义"：KV 缓存 = 边读边做的摘要卡、用显存换算力，还能照 v5/02 亲手把"KV 缓存要 100G"的错账翻案成 16G；FP8 = 8 位只剩 256 个格点的粗尺子，并且记死了"支持 FP8 权重 ≠ 以 FP8 运算"，所以"20 系竟然支持 FP8"那种标题党我不再上当；PagedAttention = 把 KV 切成小块按需分配，别按上限整块预留、浪费九成；MTP = 模型里原生多训一层、一次多吐几个 token（编辑部里实习生猜、主编验收那套）；统一内存 = CPU 和 GPU 坐进同一间仓库、零拷贝，代价是算力弱所以"吞字看算力"；垃圾佬神卡 = 专淘便宜二手硬件的玩家 + 百元退役卡，v5/04 把 P104/P102/MI50/V100 一张张讲清"买显存容量，不买算力"。另外两处对我这种"看着视频学"的人特别值钱：字幕转写错误都在正文和术语表里标了正名（"抵扣"=Decode、"障碍核心"=Tensor Core、"马林内核"=Marlin），同一组数字换算成钱和等待秒数（TTFT ≈ 输入 token ÷ PP），我第一次能自己判断一条跑分能不能信。

## 遗留问题清单

以下 3 条是我停顿超过 3 秒的地方。都是"表达问题"而不是"知识缺口"——重读或前后翻一页能自行消化，不构成不通过的理由，属可选打磨项。

1. 【低】v3/07 末段（内核与算子，FlashAttention 一段）：`**FlashQLA**（口播似为 FlashQLA，实指 FlashInfer 一系）`——加粗词和括号里的解释是同一个词，自指了。我反复读了两三遍才确定 FlashQLA 和 FlashInfer 到底是一个东西还是两个。建议改成"（视频口播听着像'FlashQLA'，实际指的是 FlashInfer 这一族）"，一句话消除歧义。
2. 【低】v6/01 开头 debug 类比的最后一步：`写进回归测试（开源复现）`。"回归测试"是全书唯一一个没给白话解释的编程黑话，而且括号把"写回归测试"和"开源复现"画了等号，这两个并不是一回事——我卡在"到底是要写测试，还是要开源"上。建议换成"把结论写成别人能一键复跑的脚本（开源复现）"，类比的画面感就接上了。
3. 【低】v4/06（TP vs PP）：`每层 2 次，一次前向固定约 129 次`——为什么每层是 2 次全书没有明说。我是靠回头翻 v1/03 的"每层 = 注意力 + FFN"倒推出"两步各合并一次"的，这是我自己补的逻辑。补半句"注意力、FFN 各触发一次合并"即可，这章的 129 次账对新手就完全透明了。

不计入问题（停顿不足 3 秒、语境可自行消化，仅备案）：v2/02 支持表里的 `RDNA3.5`（只是 AMD 架构代号标签，行名才是重点）；v4/07"怎么验证"里的 BIOS 选项 `Above 4G Decoding`（验证小节按书首声明可跳过）；"FPS 游戏""版本答案""怨种"这类口语（上下文能猜出来）。
